Django Weather Web App

A modern Weather Web Application built with Django, TailwindCSS, and Weather APIs to provide real-time weather information for cities around the world.
The application fetches live weather data from external APIs and displays it through a clean and responsive UI.

🚀 Features
🌍 Real-time Weather Data using API integration
🎨 Modern UI built with TailwindCSS
🔎 City-based Weather Search
⚡ Fast Backend powered by Django
🛡️ Form Validation using Django Forms
📱 Responsive Design for mobile and desktop
🌡️ Displays:
Temperature
Weather Condition
Humidity
Wind Speed
Location Information
